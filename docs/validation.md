## 本轮修复

- 纠正综合搜索的 `q` 参数和 `post → link` 类型映射，防止错误参数返回空的成功结果。
- 草稿使用编辑数据接口回读，删除显式带 `draft=1`；标题更新延迟时有界重试读回，不重复写入。
- 守护进程停止时关闭监听，避免端口残留。
- 表格与 CSV 从接口结果中提取记录，名称和个人评分不再被元数据列挤掉。
- 补齐根评论 `page/is_first` 参数，楼中楼使用末条已读取评论的 ID 推进游标。
- 已有会话的兼容 SDK 查询不再等待官网首页加载；创作者读取直接调用签名接口。
- 旧版 REST 查询遇到验证码时返回 428，认证、限流、网络错误分别返回 401、429、503。

| REST 查询 | 服务启动、游戏、短评摘要、游戏搜索、本人帖子读取成功，测试服务已关闭 |
| 全量评论、连续短评查询 | 部分请求触发验证码，明确报错并停止该项请求；不计为真实全量读取成功 |
| 创作者统计 | 没有可用的本人文章；已做接口契约测试，真实统计查询不适用于本次账号状态 |

本轮线上查询为只读操作。验证码按平台限制记录，不自动重复请求或处理验证码；分页、游标、错误状态和输出格式同时用合成数据测试覆盖。公开写入和各浏览器完整真实登录仍需分别验收。

接口属于平台的非公开协议。`accepted` 和 `verified` 分别表示接收与回读确认；请求失败或结果未知时不自动重发写请求。
